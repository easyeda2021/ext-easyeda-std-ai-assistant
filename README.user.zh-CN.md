# AI 助手 · 嘉立创EDA标准版扩展

版本 v{{VERSION}} · 项目地址：<https://github.com/easyeda2021/ext-easyeda-std-ai-assistant>

把大模型接进 **嘉立创EDA标准版** 的原理图与 PCB 编辑器：
原理图审查、器件标准化、BOM 分析、PCB / 画布视觉评审、按需求生成原理图、
图片生成符号。

> 仅支持 **嘉立创EDA标准版（Std / v6）**；专业版（Pro）的扩展体系不通用。

## 使用前提

- 嘉立创EDA 标准版（v6）
- 一个 OpenAI 兼容或 Anthropic 兼容的模型接口与 API Key
  （调用费用由你的模型供应商收取）
- 使用 Agent 相关功能时，模型需要支持 tool / function calling

## 能做什么

- **原理图审查**：整工程网表，检查悬空脚、命名冲突、未命名网络
- **器件标准化**：找出缺封装 / 型号 / 供应商 / 料号的元件，用系统库与模型知识补全
- **BOM 分析**：缺值、缺封装、重复物料与采购建议
- **PCB / 截图评审**：板框、布局、网络统计 + 画布截图交给视觉模型
- **生成原理图**：优先用 EDA 系统库的真实器件
- **符号生成**：按图片或需求画出边框、引脚与完整属性
- **Agent**：读取网表 / BOM / 截图，直接修改元件、连线与属性
- **多供应商 / 多模型**：同时保存多个接口，面板上随时切换
- **中英双语界面**：跟随编辑器语言自动切换

## 安装

1. 嘉立创EDA → **高级 → 扩展 → 扩展配置 → 加载扩展**
2. **一次性全选**本目录下的全部文件（`manifest.json`、`locale.txt`、
   `icon.svg`、`app.js`）
3. 扩展 ID 自行填写一个英文标识（例如 `aiassistant`），并记住它
4. 刷新页面，从 **高级 ▸ AI 助手** 打开面板

注意事项：

- `README.md`、`README.zh-CN.md`、`安装说明.txt`、`INSTALL.en.txt` 只是说明文档，
  选或不选都不影响加载。
- 扩展 ID 会拼进命令名、本地配置也以它为键，**安装后不要改**。
- 升级时先移除旧扩展，再用同一 ID 加载新文件。

## 首次使用

1. 打开 **设置**：选择协议，填写接口地址 / API Key / 模型，可点「测试连接」
2. 点胶囊（原理图审查 / BOM 分析 / 器件标准化 / 生成原理图 / 识别符号 …）
   修改需求，按 `Ctrl + Enter` **发送**
3. 审查类任务结束后出现**报告卡片**：可预览，或下载 Markdown / HTML
4. 面板右上角**日志**图标打开独立日志窗口，可「复制全部」
5. 输入框支持**粘贴 / 拖入图片**；运行中点红色方形按钮可停止

## 数据说明

API Key 只保存在本机（扩展配置 + 本地存储）。只有在你执行审查或生成任务时，
设计数据才会发送给你配置的模型供应商；调用费用由该供应商收取。

## 疑难排查

面板 → **设置 → 复制诊断信息**（含扩展 ID、API/对话框可用性、文档类型、
模型配置与最近日志）。常见原因：

- 扩展 ID 填错 → 菜单命令不触发
- 接口地址被 CORS 拦截 → 请求失败
- 模型不支持 function calling → Agent 工具不可用

## 已知问题

- **跨图纸网络**依赖网络标签推断；总线、无 junction 的交叠导线等复杂情况
  可能与编辑器自带网表有出入。
- **系统库检索**需要已登录的嘉立创EDA 会话；失败时退回由模型生成符号。
  内置模板只覆盖常用器件（R/C/L/D/LED/开关/三极管/晶振/连接器）。
- **超大工程**在审查前会被裁剪（约 24k 字符、300 个元件、200 行 BOM），
  可能只审查到其中一部分。
- **Agent 需要模型能力**：模型须支持 tool / function calling；
  OpenAI 兼容网关还须允许浏览器跨域（CORS）。
- **英文界面**按字典逐条替换，未收录的文案仍显示中文；无法识别的编辑器语言按英文处理。
- **扩展 ID 安装后固定**：改 ID 会导致设置丢失、菜单失效。
- **V6 没有工具栏按钮**：请从 **高级 ▸ AI 助手** 打开面板。
- **部分导入图元无法由 Agent 删除**，如有残留请在编辑器里手动删除。
